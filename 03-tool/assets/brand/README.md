# Teloa 品牌伙伴

本目录原样复用 Teloa 已定稿的本地品牌素材：平面圆形头像、安全岗位小松鼠、专注表情与「拿捏」无字图。角色为小松鼠 Teloa，沿用森林绿、奶油色、圆耳与三段软头冠；这些复用素材均与来源文件字节一致。

README 海报使用终版岗位素材中的立体安全分析师。`teloa-security-master.png` 是原样保存的 1254 × 1254 透明母图；`readme-hero.html` 是独立文字与版式源文件，默认英文，支持 `?lang=zh-CN`、`en`、`ja`、`ko`、`de`、`fr`、`es`。`readme-hero.<lang>.png` 是对应语言的 1600 × 600 海报导出，文字与背景由 HTML 排版，角色原稿保持不变。各语言 README 直接使用 PNG，点击海报打开对应语言的在线工具。

头像用于本项目标识，安全岗位形象与表情用于介绍和静态提示。它们不代表评估状态、认证结果或工具已经替用户完成安全工作。提示文案用 HTML 排版，随界面语言切换。
