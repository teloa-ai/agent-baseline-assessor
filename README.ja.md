# エンタープライズエージェントのID・認可セキュリティベースライン · 自己評価ツール

[简体中文](README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md)

本プロジェクトは2つの部分で構成される。1つは、エンタープライズエージェントの ID と認可に関するセキュリティ標準であり、もう1つは、その標準に照らして自己評価を行う静的ツールである。ツールにバックエンドは不要で、評価データは利用者自身のブラウザにのみ保存される。

## ディレクトリ

```
01-standard/   ベースライン本文（Markdown）
02-usage/      自己評価の手順、デプロイ方法、評価ルール
03-tool/       静的な自己評価ページ、データ、Excel テンプレート、スクリプト、デプロイ設定
.github/       GitHub Pages への自動公開ワークフロー
```

## 読む順序

1. **[01 標準](01-standard/ja/baseline-v1.0.md)**：エンタープライズエージェントのID・認可セキュリティベースライン v1.0。要件は 240 件で、10 章・62 節から成り、L1（基礎）、L2（標準）、L3（強化）の3レベルで累積する。L1 は 90 件、L2 はこれに 137 件を追加、L3 はさらに 13 件を追加する。用語、リファレンスアーキテクチャ、脅威モデル、付録の対応表はすべてこの文書に含まれる。ベースライン本文は中国語版を正本とし、他の言語版は翻訳である。
2. **[02 利用方法](02-usage/ja/usage.md)**：自己評価の実施方法、オンライン・オフライン・私有化デプロイの3つの利用方法、評価ルール、GitHub Pages または Cloudflare Pages への公開、データの保存方式。
3. **[03 ツール](03-tool/docs/ja.md)**：ツールのディレクトリ構成、主要コマンド、ベースライン改訂後のツール更新方法、サードパーティ製コンポーネント。

## クイックスタート

- すぐに自己評価を行いたい場合：オンラインのアドレスを開くか、zip を展開して `03-tool/index.html` をダブルクリックする。
- Excel で入力したい場合：`03-tool/offline/baseline-assessment.xlsx` を使用する。
- 自前でデプロイしたい場合：[02 利用方法](02-usage/ja/usage.md) の公開の章を参照。
