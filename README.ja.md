エンタープライズエージェントのID・認可セキュリティベースラインは、企業環境で用いられる AI エージェントが ID と認可に関して満たすべきセキュリティ要件を定める。エージェントの1回の行為の背後にある基本的な問い、すなわち誰が開始したのか、誰の代理で実行されるのか、何をしてよいのか、資格情報はどこから来るのか、結果を誰が見るのか、問題が起きたときにどのように責任を追及するのか、に答えるものである。

本リポジトリには、ベースライン本文と付属の自己評価ツールが含まれる。本文は、プラットフォーム構築の設計インプット、ベンダー評価の質問票、セキュリティレビューのチェックリストとしてそのまま利用できる。自己評価ツールは静的な Web ページであり、要件ごとに評価結果を記録し、成熟度レポートと Excel 評価表を生成する。評価データは利用者自身のブラウザにのみ保存される。

## 対象範囲

V1〜V7 は、エージェントの1回の行為が進む順序に沿って並ぶ。V8〜V10 は、セッションをまたいで残るデータ、エージェント及び監査記録を扱う。

## レベル

レベルは累積的である。あるレベルを達成するには、そのレベル以下の適用可能な要件をすべて満たす必要がある。

- **L1 基礎**：欠如すると、越権、資格情報の漏えい又は責任追及ができない状態が直接生じる。企業内で利用するすべてのエージェントプラットフォームが満たすべきレベルである。
- **L2 標準**：主流の企業セキュリティレビューで求められる機能。内部データを扱い、複数の業務システムに接続するプラットフォームを対象とする。
- **L3 強化**：多層防御及び精緻なガバナンス。金融、医療、重要インフラなどの規制の厳しい業界、又は機微性の高いデータを扱うプラットフォームを対象とする。

プラットフォームがある機能を備えていない場合（例えば MCP に対応していない場合）、該当する節は節全体を適用外とし、適合率の計算から除外する。判定ルールは本文第 6 章に示す。

## クイックスタート

- **ベースラインを読む**：[01-standard/ja/baseline-v1.0.md](01-standard/ja/baseline-v1.0.md)
- **オンラインで評価する**：本リポジトリから公開される GitHub Pages のサイトを開く。右上で言語を切り替えられる。
- **オフラインで評価する**：リポジトリをダウンロードし、`03-tool/index.html` を開く。機能はオンライン版と同じで、ネットワーク接続は不要である。
- **Excel を使う**：[`03-tool/offline/baseline-assessment.xlsx`](03-tool/offline/baseline-assessment.xlsx)（中国語）に入力するか、ツールの **データ** ページにある「空白の評価表をダウンロード」から日本語の空白の評価表を取得する。評価表には集計数式とギャップ一覧が含まれ、入力後はツールに読み込み直すことができる。
- **私有化デプロイ**：ツールは静的ファイルのみで構成され、強化済みの nginx 設定と Dockerfile が付属する。手順は[利用方法](02-usage/ja/usage.md)を参照。
