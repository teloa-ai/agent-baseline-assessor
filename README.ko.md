# 엔터프라이즈 에이전트 신원 및 인가 보안 기준선 · 자가 평가 도구

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어** · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md)

이 프로젝트는 두 부분으로 구성됩니다. 하나는 엔터프라이즈 에이전트의 신원과 인가에 관한 보안 표준이고, 다른 하나는 이 표준에 따라 자가 평가를 수행하는 정적 도구입니다. 도구는 백엔드가 필요하지 않으며, 평가 데이터는 사용자 본인의 브라우저에만 저장됩니다.

## 목차

```
01-standard/   기준선 본문(Markdown)
02-usage/      자가 평가 절차, 배포 방식, 채점 규칙
03-tool/       정적 자가 평가 페이지, 데이터, Excel 템플릿, 스크립트 및 배포 설정
.github/       GitHub Pages 자동 배포 워크플로
```

## 읽기 순서

1. **[01 표준](01-standard/ko/baseline-v1.0.md)**: 「엔터프라이즈 에이전트 신원 및 인가 보안 기준선」 v1.0. 요구사항 240개, 10개 장, 62개 절로 구성되며, L1(기본), L2(표준), L3(강화) 세 등급으로 누적됩니다. L1은 90개, L2는 여기에 137개를 더해 추가되고, L3는 13개가 다시 더해집니다. 용어, 참조 아키텍처, 위협 모델, 부록 매핑이 모두 이 파일에 있습니다. 기준선 본문은 중국어판을 기준으로 하며, 다른 언어판은 번역본입니다.
2. **[02 사용 방법](02-usage/ko/usage.md)**: 자가 평가 수행 방법, 온라인·오프라인·사내 배포의 세 가지 방식, 채점 규칙, GitHub Pages 또는 Cloudflare Pages 배포, 데이터 저장 방식을 설명합니다.
3. **[03 도구](03-tool/docs/ko.md)**: 도구의 디렉터리 구조, 자주 쓰는 명령, 기준선 개정 후 도구를 업데이트하는 방법, 제3자 구성 요소를 설명합니다.

## 빠른 시작

- 바로 자가 평가하려면 온라인 주소를 열거나, zip을 풀고 `03-tool/index.html`을 더블클릭하십시오.
- Excel에서 작성하려면 `03-tool/offline/baseline-assessment.xlsx`를 사용하십시오.
- 직접 배포하려면 [02 사용 방법](02-usage/ko/usage.md)의 배포 장을 참고하십시오.
